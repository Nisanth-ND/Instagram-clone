# Instagram Clone using PHP & MySQL

A simple Instagram Clone Web Application built using PHP, MySQL, HTML, CSS, and Apache (XAMPP).

## Features

- User Registration
- User Login & Logout
- Session Authentication
- User Profile
- Create Post
- View Posts
- Edit Posts
- Delete Posts

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Apache (XAMPP)

## Database

Import the `db.sql` file into MySQL before running the project.
